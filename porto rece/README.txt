MY DIGITAL SPACE — PORTOFOLIO HTML & CSS

Isi folder:
- index.html   : halaman Home
- about.html   : halaman About + tabel data
- projects.html: halaman Projects
- contact.html : halaman Contact + form
- style.css    : stylesheet eksternal
- assets/profile.svg : ilustrasi profil lokal

Cara menjalankan:
1. Ekstrak folder my-digital-space.
2. Buka folder di Visual Studio Code.
3. Klik kanan index.html lalu pilih "Open with Live Server" (jika ekstensi Live Server tersedia),
   atau buka index.html langsung di browser.
4. Navigasi antar halaman memakai menu di bagian atas.

Sesuai materi PPT:
- Struktur HTML5 dan elemen semantik: header, nav, main, section, article, aside, footer.
- Link internal antarhalaman, image dengan alt, list, table, form, input, select, textarea, button.
- CSS eksternal di style.css, CSS internal pada index.html, dan contoh inline style.
- Selector elemen, class, pseudo-class hover/focus, warna HEX/RGBA, box-sizing: border-box,
  margin, padding, border, border-radius, box-shadow, Flexbox, unit relatif, dan media query.
- Tidak menggunakan framework atau template.

Catatan:
- Ganti nama, profil, detail, dan deskripsi project sesuai data kamu.
- Form contact hanya tampilan HTML; belum mengirim pesan ke email/server.
